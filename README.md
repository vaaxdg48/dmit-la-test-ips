## 路由分析：回程走哪条线才是关键

延迟只是表象，路由才是核心。DMIT 洛杉矶的两条产品线，回程路由差异很大：

### LAX.Pro — CN2 GIA 回程

LAX.Pro 系列走的是电信 CN2 GIA 回程，traceroute 可以看到经过 `59.43.x` 段的 CN2 骨干节点，这条线路的特点是晚高峰稳定性明显好于普通线路。联通和移动用户走的是对应的优化路由，不是单纯的 CN2，但整体质量也在 Pro 级别。

### LAX.EB — 普通优化线路

LAX.EB 走的是大众线路，回程不保证 CN2，价格相对便宜。如果你的使用场景对延迟不敏感，或者主要在白天使用，EB 线路性价比更高。

对了，有一点容易被忽略：DMIT 的 Pro 套餐是**双向 CN2 GIA**，去程和回程都走优化线路，不是只有回程优化。这个在同价位产品里不算常见。
